# مطعم ليالي الباب

موقع عربي متجاوب للمنيو وسلة الطلبات وطلب واتساب، مع لوحة لتعديل الأصناف والأسعار ورقم واتساب والعنوان.

## تعديل رقم واتساب لاحقًا

افتح لوحة الإدارة، وعدّل حقل **رقم الواتساب** برقم دولي يتضمن رمز الدولة، دون علامة `+` أو مسافات (مثال توضيحي: `9639XXXXXXXX`) ثم اضغط **حفظ الإعدادات**. التغييرات محفوظة في المتصفح نفسه، لذلك هذه النسخة مناسبة للتجربة على جهاز واحد.

## ملاحظات مهمة قبل النشر العام

- المنيو والإعدادات تُحفظ حاليًا في `localStorage` داخل المتصفح؛ التغييرات لا تنتقل تلقائيًا إلى أجهزة الزبائن أو أجهزة الإدارة الأخرى.
- مسارات API وقاعدة MongoDB مضمّنة كمخطط خلفي اختياري، لكنها ليست مصدر بيانات الواجهة الحالية. لتشغيل إدارة مشتركة بين جميع الزبائن يلزم ربط الواجهة بالـ API وتأمين لوحة الإدارة.
- عند تشغيل الـ API، أنشئ ملف `.env` من `.env.example` واضبط `MONGODB_URI` و`ADMIN_EMAIL` و`ADMIN_PASSWORD` و`JWT_SECRET` بقيم قوية وفريدة. لا تنشر أسرار `.env` ولا تستخدم كلمات المرور الافتراضية.
- لم يُضف رقم واتساب نهائي؛ يمكن تغييره لاحقًا من لوحة الإدارة كما طلبت.
